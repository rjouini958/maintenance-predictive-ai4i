Le CSV est une copie sans modification extraite de l'archive officielle.
Son SHA-256 et son URL de téléchargement sont dans source.json.
Les colonnes sont renommées uniquement en mémoire par src/project.py.
Le dataset officiel est synthétique : ce ne sont pas des mesures d'une usine partenaire.
Les règles de génération contribuent à expliquer les bons résultats des modèles physiques.
